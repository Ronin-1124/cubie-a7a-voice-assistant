## 一、Demo 说明

### 1. 目标

本地、不连云：

```text
麦克风 → KWS 唤醒词 → ASR 指令转文字 → 打印结果 → 回到监听
```

| 已实现 | 未在本链路内 |
|--------|----------------|
| 麦采集 / `kws_mic` | TTS 播报（见 TTS 文档） |
| KWS + 流式 ASR | LLM / 业务执行 |
| 预加载、尾静音收句 | NPU 加速 ASR/KWS |
| 离线 wav 回归 | — |

### 2. 硬件与环境

| 名称 | 含义 |
|------|------|
| **A733** | 全志 SoC；CPU 大小核 + Vivante **NPU**（本链路未用 NPU） |
| **Cortex-A76 / A55** | 大核 CPU6–7 / 小核 CPU0–5 |
| **ALSA** | Linux 声卡接口 |
| **plughw:1,0** | 声卡 1 设备 0（可自动重采样） |
| **kws_mic** | 虚拟单声道麦：取 **右声道**（本板耳机麦有效通路） |
| **TRRS** | 四段 3.5mm 耳机（带麦） |

### 3. 链路与术语

```text
16 kHz PCM ──► KWS ──wake──► ASR(streaming + endpoint) ──► 文本
```

| 名称 | 含义 |
|------|------|
| **PCM** | 原始采样波形 |
| **KWS** | Keyword Spotting，唤醒词检测 |
| **Wake word** | 唤醒词（如「你好小瑞」） |
| **Hotword** | ASR 热词偏置，**不是**唤醒 |
| **ASR / STT** | 语音识别 / 语音转文字 |
| **VAD** | 语音活动检测；本 Demo 主路径用 ASR **endpoint** 收句 |
| **Endpoint** | 句尾静音检测，结束本轮识别 |
| **RTF** | 处理时间 / 音频时长；&lt;1 为快于实时 |
| **RSS** | 进程常驻内存 |
| **INT8** | 8-bit 量化 |
| **ONNX / ONNX Runtime** | 模型格式 / 推理引擎 |
| **sherpa-onnx** | k2-fsa 端侧语音框架 |
| **Zipformer** | 流式编码器结构 |
| **CTC** | 序列识别训练/解码方式之一 |
| **chunk-8** | KWS 分块配置（更低算法延迟） |

### 4. 模型

| 模块 | 模型 | 体积（约） |
|------|------|------------|
| KWS | `sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20` INT8 chunk-8 | **~5.3 MB** |
| ASR | streaming Zipformer2-CTC small 中文 INT8 | **~25 MB** |
| VAD（备用） | Silero VAD | ~0.2–0.6 MB |
| 运行时 so | libonnxruntime + sherpa | **~37 MB** |

唤醒词文件：`keywords_wake.txt`（主推「你好小瑞 / 小瑞小瑞」；单独「你好」阈值更严防误触）。

### 5. 使用方法

```bash
ssh a7a
cd ~/npu_demos/voice_assistant

./run_assistant.sh              # KWS + ASR 循环（默认快路径）
./run_assistant.sh --once
./mic_level_test.sh             # 电平：看 AC peak
./run_kws_mic.sh                # 仅 KWS
./run_asr_mic.sh                # 仅 ASR
./run_offline_test.sh           # 无麦，wav 回归
```

### 6. 关键问题

| 现象 | 原因与处理 |
|------|------------|
| 耳机说话无反应 | 有效信号在右声道；用 `setup_mic.sh` + `kws_mic`，抬 ADC 增益 |
| 空循环 `WAKE:你好` + 空 text | 短词误触 + 无冷却；已提高阈值、非空才结束 ASR、cooldown |
| 体感识别慢 | 旧路径固定 5s 录音 + 每次冷加载；用 `assistant_fast.py` 预加载 |

### 7. 能力边界

适合：中文短指令助手原型、算力与链路验证。  
不适合单独当：嘈杂开放工位最终 WER、完整对话（需 LLM+TTS）。

## 二、性能报告（2026-08-11）

**平台：** aarch64，8 核（6×A55 + 2×A76），内存 5.8 GiB，CPU only。

### 1. 启动与内存（Python 预加载）

| 阶段 | 耗时 | RSS |
|------|------|-----|
| 基线 | — | 32 MB |
| 加载 KWS | **2.12 s** | → 71 MB（+38） |
| 加载 ASR（2 线程） | **2.58 s** | → **129 MB**（+58） |
| **合计** | **~4.7 s** | **~130 MB** |

CLI 每次冷启动 ASR：加载约 **2.56 s** + 解码 0.45 s（5.6 s 音频）→ 每轮多等 ~2.5 s 加载。

### 2. KWS（1 线程，预热 5 次平均）

| 指标 | 结果 |
|------|------|
| RTF | **≈ 0.10**（0.096–0.106） |
| 1.78 s 唤醒音频 | 解码 ~0.19 s |
| 静音/噪声负例 | 默认词表下无误触发 |

→ 常驻监听可行。

### 3. ASR（2 线程，预热 5 次平均）

| 音频 | 时长 | 文本（摘要） | RTF |
|------|------|--------------|-----|
| 帮我打开灯 | 1.78 s | 正确 | **0.078** |
| 今天天气怎么样 | 2.06 s | 正确 | **0.067** |
| 会议安排句 | 3.46 s | 正确 | **0.067** |
| 真人口语 0.wav | 5.61 s | 正确出字 | **0.074** |

**ASR RTF ≈ 0.067–0.083（约 12–15× 实时）。**

### 4. 线程与绑核（同一句 5.61 s）

| 配置 | RTF |
|------|-----|
| 1 线程 | 0.088 |
| **2 线程** | **0.075**（推荐） |
| 4 线程 | 0.079 |
| **A76×2** | **0.073** |
| A55×2 | 0.209（仍实时，约慢 3×） |

### 5. 端到端体感（模型已加载）

```text
唤醒(流式) → 说指令(~2s，边说边算) → 尾静音(~0.8s) → 出字
```

瓶颈主要是说话与句尾静音，不是算力。  
旧路径：固定 5s 录音 + 2.5s 冷加载 ≈ 7.5–8 s。

### 6. 功能回归（offline_test）

| 套件 | 结果 |
|------|------|
| KWS | 7/7（单独 TTS「你好」严格阈值可为 WARN） |
| ASR | 8/8 |
| wake+cmd 流水线 | 3/3 |

### 7. 总评

| 维度 | 评级 |
|------|------|
| ASR 实时性 | **优** |
| KWS 常驻 | **优** |
| 内存 | **优**（~130 MB） |
| 冷启动 | 中（~4.7 s，启动做一次） |

**建议：** 预加载 + ASR 绑 A76 + 2 线程 + 长唤醒词。
